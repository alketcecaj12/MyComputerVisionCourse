# 👁️ Computer Vision Course
### Teaching machines to see — one pixel at a time

A practical **9-week Python course** covering image processing, object detection, and video analysis using **OpenCV** and **YOLO**. Every week is a self-contained Jupyter notebook — open, run, experiment.

## 🗓️ Curriculum

| Week | Topic | Key Concepts |
|------|-------|-------------|
| **Week 1** | Python & Image Basics | NumPy arrays, environment setup, first image operations |
| **Week 2** | Image I/O & Properties | Read, write & display · Color channels · Image shape & structure |
| **Week 3** | Pixels & Region of Interest | Pixel access · ROI extraction · Creating new images from scratch |
| **Week 4** | Geometric Transformations | Resize, rotate & flip · Affine transforms · Perspective warping |
| **Week 5** | Filtering & Smoothing | Blurring techniques · Edge detection · Morphological operations |
| **Week 7** | Contours & Feature Detection | Finding contours · Shape analysis · Feature extraction |
| **Week 8** | Object Detection | Haar cascades · YOLO integration · Bounding boxes & confidence scores |
| **Week 9** | Video & Real-time Inference | Video capture · Frame processing · Live detection pipeline |

## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/alketcecaj12/ComputerVisionCourse
cd ComputerVisionCourse

# 2. Install dependencies
pip install opencv-python numpy matplotlib jupyter ultralytics

# 3. Launch the first week
jupyter notebook week1_python/
```

Work through the weeks in order — each one builds on the previous.
